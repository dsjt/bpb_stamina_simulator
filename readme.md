# BackpackBattles スタミナ計算機

BackpackBattles の武器構成におけるスタミナ管理をシミュレーションするブラウザツールです。

**公開URL**: https://dsjt.github.io/bpb_stamina_simulator/

## 機能

- 複数武器のスタミナ消費をタイムライン上に可視化
- バナナ・ヒーローポーションなどのスタミナ回復アイテムを考慮したシミュレーション
- ヒート・フリーズによるクールダウン変化に対応
- パズルボックス・サルでもわかる鍛冶の効果を再現
- スタミナ切れのタイミングと回数を分析結果として表示

## 使い方

1. **武器登録** — プリセットから選択して「武器追加」。CD・加速・スタミナ消費を個別に編集可能
2. **アイテム追加** — バナナ、ポーション、スタミナバッグなどを追加
3. **オプション設定** — ヒート/フリーズ値、パズルボックス対象を必要に応じて設定
4. **計算実行** — スタミナ推移グラフと分析結果を確認

## 対応アイテム

| アイテム | 効果 |
|---------|------|
| バナナ | CD 5秒ごとにスタミナ +1 回復 |
| ヒーローポーション | スタミナ不足時に自動使用、+2 回復 |
| スタミナバッグ | 最大スタミナ +1（複数個対応） |
| 勇気の星 | 全武器のスタミナ消費 -5% |
| サルでもわかる鍛冶 | 指定した武器のスタミナ消費 -25% |
| パズルボックス | 0〜5秒: 使用速度 -20% / 5秒以降: +55% |

## シミュレーション仕様

- 時間刻み: 0.02秒
- 基本スタミナ上限: 5（スタミナバッグで増加）
- 自然回復: 1スタミナ/秒
- ヒート: 1スタックにつきクールダウン 2% 短縮
- フリーズ: 1スタックにつきクールダウン 2% 延長
- クールダウン計算: `実効CD = 基本CD ÷ (1 + 合計加速% / 100)`
